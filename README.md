## 📂 Registry Curriculum Structure

The repository consolidates the lab submission history (Weeks 1–3 and 6–12) into 10 distinct architectural modules:

### 🧩 Core Fundamentals & Tooling
*   **Module 1: Cross-Platform Language Metrics**
    *   *Focus:* Comparative analysis matrices matching Java's WORA bytecode execution rules against low-level compiled paradigms (C/C++) and interpreters (Python, JS).
*   **Module 2: OpenJDK Environment Provisioning**
    *   *Focus:* System environment variable mapping targeting automated terminal calls for `JAVA_HOME` and system `PATH` binaries under Windows.
*   **Module 3: Oracle JDK Deployment**
    *   *Focus:* Dual-runtime paths, compiler diagnostic validation strings (`javac -version`), and baseline program target executions.

### 📐 Structural OOP Elements
*   **Module 4: Primitive Typologies & Conversions**
    *   *Focus:* Handling primitives, safe implicit widening promotions, data-truncating explicit narrowing type-casts, and syntax keyword exclusions.
*   **Module 5: Core Class Architecture**
    *   *Focus:* Static field tracking pools, field encapsulation, overloaded constructor frameworks, constructor chaining, and `this` variable references.
*   **Module 6: String Manipulation Mechanics**
    *   *Focus:* String Constant Pool (SCP) deduplication caches vs general heap object strings, mutable `StringBuffer` thread-safety optimizations, and custom text token parsing.

### ⚡ Advanced Execution Engineering
*   **Module 7: Inheritance & Runtime Polymorphism**
    *   *Focus:* Multi-level class tree extensions, invoking parent constructor matrices via `super()`, method overriding rules, and dynamic method dispatch routines.
*   **Module 8: Defensive Exception Engineering**
    *   *Focus:* Layered multi-catch blocks, explicit checking via `throw` and method `throws` propagation signatures, deterministic `finally` state execution, and custom user-defined validation types.
*   **Module 9: Stream Processing & Multithreading**
    *   *Focus:* 8-bit Byte Streams vs 16-bit Unicode Character Streams, `Thread` extensions vs `Runnable` tasks, execution pacing (`sleep`), and thread synchronization using `join()`.
*   **Module 10: Thread Priority, Synchronization & Lambdas**
    *   *Focus:* Thread priorities (`MIN`/`NORM`/`MAX`), `synchronized` methods and blocks, race conditions vs thread-safe counters, a ticket-booking simulation, and lambda expressions with functional interfaces (generics, block bodies, `forEach`/`filter`, sorting, lambda-based threads).
